[TARGETS_SIMULATION]
# À vérifier absolument dans Linkage avant fabrication :
# 1. Anti-squat au sag (25 mm) : cible 100–115%
#    (contrer la poussée 150 Nm Bafang M620 à l'accélération)
# 2. Belt/chain growth total sur 160 mm de débattement : < 2 mm
#    (sinon la courroie Gates CDX décrocha ou surcharge le moyeu)
# 3. Leverage ratio à sag : ~2.8–3.2 (pour amortisseur 205×60)
# 4. Progressivité du leverage ratio : 20–30% début → fin course
#    (éviter le talonage avec la masse totale pilote + engin)
# 5. Chemin de roue arrière : axe AR doit reculer légèrement
#    en compression (rearward axle path) — naturel avec Horst link

[NOTES]
# — Le pivot Horst quasi-concentrique au BB donne un comportement
#   similaire à un single-pivot dans la première phase de compression,
#   puis diverge en fin de course grâce au point de pivotement virtuel.
# — La courroie Gates CDX ne supporte pas de tension rouleau agressif.
#   L'idler au point de fente est un guide simple (pas de tendeur actif).
# — Avec un moyeu 3×3.bike, le rapport de transmission varie selon le
#   rapport engagé ; le chain/belt growth doit être < 2 mm sur TOUS les
#   rapports pour éviter le sauts de courroie (validation par calcul).
